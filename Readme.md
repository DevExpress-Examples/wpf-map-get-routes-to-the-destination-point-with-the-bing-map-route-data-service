
# Map for WPF - How to Get Routes to the Destination Point with the Bing Map Route Data Service  

>[!warning]
> On May 21, 2024, Microsoft announced that [Bing Maps for Enterprise and its API will be discontinued](https://blogs.bing.com/maps/2024-05/Microsoft-Announces-Vision-for-Next-Generation-of-Enterprise-Maps). Azure Maps will be a single unified enterprise mapping platform available from Microsoft. The Bing Maps Calculate a Route API is deprecated. Refer to the following article for migration information: [Migrate Bing Maps Calculate a Route API](https://learn.microsoft.com/en-us/azure/azure-maps/migrate-calculate-route)
